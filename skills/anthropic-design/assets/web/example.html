Which radius should the task cards use?

Use --ad-radius (8px) for the cards and keep 12px for the column they sit in. The column has 4px of padding, so the nested corners stay concentric.

Why not match them

Two boxes with the same radius, one inside the other, look pinched at the corners. The inner radius should be the outer radius minus the padding between them. 

.column { border-radius: 12px; padding: 4px; }
.card   { border-radius: 8px; }
