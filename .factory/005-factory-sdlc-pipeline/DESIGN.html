D4Design holds flagged concerns and decisions, plus a design/ folder of artifacts in the task directory (mocks, diagrams, schemas). It can be skipped with a reason.Mocks only. The playbook's spec also carries decisions and concerns.R2
D5The plan's test plan tags each test fast or heavy. Build owns fast tests. Test reruns them as regression, then runs the heavy ones. A bug fix starts with a committed failing test.Untiered gates, where nobody knows what must pass before Test.R2
D6DEBRIEF.html lives in the task directory and is written in Build. The test report is REPORT.html in the task directory (amended 2026-11-02; it was docs/reports/).Debrief in reports, which mixes build notes with verification evidence.R2, R4

D8Loop-back: out-of-scope findings become draft-intent tasks in backlog/. Repeated mistakes become proposed memory edits.Silent fixes, or findings left in a report.R2
